## 三、读报告时的两个提醒

1. **报告里的"坐标"会过期**：报告中的 commit sha、上游版本、设备状态都是**当时**的实测值。
   要当前值，看最新一轮报告或 `_ofm/CHANGES.md` 末尾。
2. **报告里的"待办"可能已完成**：例如多份报告写「ADB 真人操作层待一条人类消息解锁」、
   多份报告写「实机验收待用户」，这些要在**后续报告**里找闭环结论，不要据旧报告重复劳动。
