## 1. 抓取方法（本轮换了工具：Gitee API 被限流）

Gitee 匿名 API 本轮**持续 403**（`403 Forbidden (Rate Limit Exceeded)`，换 UA、换端点、间隔重试均无效）：

```
gitee-api-gitUA  → 403   gitee-api-curlUA → 403   （/commits 与 /git/trees 都是）
```

⇒ 改用两条不依赖 API 的通道：

1. **git refs**（既有手法，UA `git/2.40`）：`.../info/refs?service=git-upload-pack` → `master=29452038d7…`；
2. **本机 isomorphic-git 浅克隆**（`/data/data/com.dshphone/files/tools/gitjs/node_modules/isomorphic-git`）：
   `clone({ url: 'https://gitee.com/iJetLi/deepseek-harness-codearts.git', depth: 100, noCheckout: true })`
   → **8.5 秒**拿到 tip 起 105 个提交与全部对象（commits/trees/blobs），之后所有 diff 都在本地算。

> 工具脚本：`tools/gitjs/_gitee_clone.mjs`（克隆）、`_gitee_delta.mjs`（逐提交变更文件）、
> `_dump_commit.mjs`（old/new/统一 diff）、`_port_plan.mjs`（逐文件三方比对）、`_capsule_sync_check.mjs`（本地 vs 远端胶囊一致性）。

## 3. 移植方法

对每个待移植文件做**三方比对**（复用第十轮的 `merge3.mjs`）：

- **base** = 上游该提交的父版本（本地克隆对象）
- **ours** = 胶囊现值（`overrides/` 优先，其次 `files/`）
- **theirs** = 上游新版本

`ours == base` ⇒ 直接取 theirs（手机版无手术）；`theirs == base` ⇒ 无需改；两者都变 ⇒ 走 merge3，
**冲突不猜**、逐块人工裁决（本轮仅 3 处冲突，全部已裁决）。

逐文件计划与冲突明细：`.scratch/round-20261016/planned/`（含 `conflicts/` 子目录）。
