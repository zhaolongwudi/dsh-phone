## 三点五、本轮实测订正的一条上游认知（勿再沿用）

「上游折叠态侧栏只有 56px 宽」这个从 `dsh-client-ui-layout` 源码读出的结论，
**在手机版窄屏抽屉里不成立**：本层 CSS 的 `width:100%!important` 把 inner root 撑到
280px，上游折叠只让**文字与面板标签消失**（文字叶节点 23→0），宽度不变。
⇒ 凡本仓库文档里写「折叠态 56px ⇒ 224px 空白」的地方，都应按此订正。

## 五、已知边界（刻意未改，防后人误判）

1. **`settings-open` 常驻态不禁用上游 toggle** —— 与本次报障（抽屉场景）无关，
   最小改动原则不动。若日后发现「设置面板开着时折侧栏也出空白」，是同一病症的
   第三条路径，可按同法加一条 `html[data-dsh-settings-open] ... .hHd-Xa_toggle`。
2. **抽屉内禁用 toggle 用 `display:none!important`** —— 上游折叠态规则会给该按钮设
   28/36px 与 display，不用 `!important` 压不住（同仓库遮罩接管先例）。
   `display:none` 同时移除可聚焦性与读屏可见性，故无需额外 `aria-hidden`/`tabindex`。
3. **JS 的排除判据（点小按钮不关抽屉）保留** —— 与 CSS 隐藏是两道独立防线。
