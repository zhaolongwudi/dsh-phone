## 判定方法（可复跑）

1. 扫出全部文档里指向**本工作区**的相对路径引用，逐个 `fs.existsSync` 判定（只算工作区内路径，
   远端仓库/vendor 里的路径本地本就没有，不算失效）；
2. 对每份候选文档读其**自述用途与坐标**，与当前实际状态对表；
3. 失效判定必须能指向一条可验证的证据（脚本不存在 / 基线 sha 过期 / 状态自述与后续文档矛盾）。
